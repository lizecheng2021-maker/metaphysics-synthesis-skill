# Output Templates

Use these templates to keep answers decisive, auditable, and easy to verify.

## Chinese Strict Reading

```text
本次只用：{八字/梅花/六爻/风水/塔罗}

断语：
{1-3句直接结论}

主证：
1. {关键证据}
2. {关键证据}
3. {关键证据}

冲突点：
{若无则写“无明显反证”；若有则说明如何裁决}

应期/数值：
{时间窗、强弱、象数范围；不要伪装成精密测量}

行动：
{做什么 / 避免什么}

验证点：
{出现什么说明应验；出现什么说明改断}

置信层级：
{高 / 中 / 低}，原因：{简短原因}
```

## Chinese Synthesis

```text
总断：
{最终裁决}

各体系分断：
- 八字：{结构和时间带}
- 梅花：{当前动象和近事}
- 六爻：{具体成败和角色}
- 风水：{空间助力/阻力}
- 塔罗：{心理和关系动力}

共同信号：
{重合点}

冲突信号：
{冲突点和裁决理由}

最终裁决：
{一句话定案}

行动清单：
1. {行动}
2. {行动}
3. {行动}

验证点：
{可观察信号}
```

## English Strict Reading

```text
System used:
{BaZi / Meihua Yishu / Liuyao / Feng Shui / Tarot}

Verdict:
{1-3 direct sentences}

Main evidence:
1. {evidence}
2. {evidence}
3. {evidence}

Conflict:
{counter-signal and how it is resolved}

Timing / range:
{timing window or symbolic range}

Action:
{what to do and what to avoid}

Verification:
{what confirms or falsifies the reading}

Confidence tier:
{High / Medium / Low} because {reason}
```

## Safety Insert

Use this when the topic involves health, law, finance, death, disaster, mental health, or safety:

```text
边界：以下只作文化和策略参考，不能替代专业判断。现实检查、医生/律师/财务顾问/安全措施优先于象征推演。
```
