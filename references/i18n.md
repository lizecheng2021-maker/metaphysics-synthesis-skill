# Internationalization Reference

Use this file when answering or writing public materials in Chinese, English, Korean, Japanese, French, or Spanish.

## Language Policy

- Answer in the user's language when the language is clear.
- Keep shell commands, file paths, repository names, script names, and classical method names exact.
- Use local divination terms instead of literal machine translation.
- Do not mix output labels across languages. For example, a Korean answer should not use Chinese labels like `断语` unless the user specifically asks.
- If the user asks in mixed language, follow the language of the direct instruction.

## README Localization Checks

Each public language page should contain:

- a native-language positioning paragraph.
- the same install options: universal clone, Codex, Claude Code, custom agent folder, shared symlink.
- five system summaries with Wikipedia links.
- one local example for each major method family.
- safety boundaries in the same language.
- no visible discussion of hidden discoverability tactics.
