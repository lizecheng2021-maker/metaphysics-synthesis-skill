# Examples

Use these examples to improve documentation, trigger coverage, and prompt shaping.

## BaZi

```text
用八字看我 2026-2036 年事业和财运，严格区分命局结构、大运、流年触发点、高置信判断和低置信推测。
```

```text
Analyze this BaZi chart for career, wealth, marriage, and health tendencies. Separate natal structure from decade luck and annual triggers.
```

## Meihua Yishu

```text
用梅花易数看这个项目从现在到正式上线，并在上线后形成可汇报数据的走势。起心动念时间是 2026-06-12 10:36，外应是西北方主管在讨论排期。
```

```text
Use Meihua Yishu with this timestamp and omen. Do not use previous readings. Give the main hexagram, moving line, changed hexagram, timing, and verification signs.
```

## Liuyao

```text
用六爻判断这个项目能否成为我升职的主功。六个数字从初爻到上爻是 5 / 4 / 25 / 12 / 22 / 17。不要串联旧卦。
```

```text
Use Liuyao for a concrete job outcome. Lines from bottom to top are 12 / 1 / 4 / 9 / 3 / 6. Read timing, role movement, blocker, and trigger.
```

## Feng Shui

```text
我的朝向是东南 146 度，主管在西北 332 度，P8 在东方 101 度，大领导在南方 196 度。按风水方位看可见度和汇报机会。
```

## Tarot

```text
用七张塔罗牌看这段关系的主线：相遇方式、阻碍、对方行动、我的行动、转折点、结果、验证点。
```

## Synthesis

```text
把之前关于事业的八字、梅花、六爻和风水信号串联，但不要重新起卦。按每卦原始问题范围分别列出，再给最终裁决。
```
