# 형이상학 종합 Skill

Codex와 AI Agent를 위한 사주명리, 매화역수, 육효, 풍수 방향 분석, 타로 리딩 종합 skill입니다.

이 저장소는 단순한 점술 프롬프트가 아니라, AI가 상징 체계를 구조적으로 다루도록 돕는 재사용 가능한 절차입니다. 먼저 체계를 고르고, 결론을 내리고, 근거를 정리하고, 시기와 행동, 검증 신호를 제시합니다.

> 문화적, 성찰적, 전략적 참고용입니다. 의료, 법률, 투자, 정신건강, 긴급상황, 안전 조언을 대체하지 않습니다.

- 타로 배열과 역방향 카드 해석
- 중국 명리학 AI Agent

## 핵심 기능

- 결론, 근거, 시기, 행동, 검증 신호를 분리합니다.
- 높은 확신의 판단과 낮은 확신의 추측을 구분합니다.
- 여러 체계를 섞기 전에 각 체계를 먼저 내부적으로 해석합니다.
- 각 방법을 `runnable`, `partial`, `blocked` 상태로 구분합니다.
- 사주는 계산 가능한 명식 정보와 해석을 분리합니다.
- 매화역수는 시간, 숫자, 외부 징조를 분명히 기록합니다.
- 육효는 초효부터 상효까지의 순서를 고정합니다.
- 풍수는 형세를 먼저 보고 방향 상징은 그 다음에 봅니다.
- 타로는 배열, seed, 정/역방향을 기록해 재현 가능한 리딩을 지원합니다.
- 매화역수 구조 계산 스크립트를 제공합니다.
- 타로 카드 추첨 스크립트와 개인정보 점검 스크립트를 제공합니다.
- 고위험 주제에는 안전 경계를 둡니다.

## 한국어 사례

### 사주명리 사례

```text
이 사주를 바탕으로 2026년부터 2036년까지의 직업운과 재물운을 분석해 주세요. 원국, 대운, 세운, 높은 확신의 결론, 낮은 확신의 추측을 구분해 주세요.
```

### 매화역수 사례

```text
매화역수로 이 제품 출시가 커리어 전환점이 될 수 있는지 봐 주세요. 질문이 떠오른 시간은 2026-06-12 10:36이고, 외부 징조는 북서쪽에서 매니저가 일정을 논의한 것입니다.
```

### 육효 사례

```text
육효로 이 프로젝트가 승진의 핵심 근거가 될 수 있는지 판단해 주세요. 초효부터 상효까지 숫자는 5 / 4 / 25 / 12 / 22 / 17입니다.
```

### 풍수 사례

```text
풍수 방향으로 제 사무실 자리를 분석해 주세요. 저는 남동쪽을 보고 앉아 있고, 직속 매니저는 북서쪽, 큰 리더는 남쪽, 다른 팀 매니저는 동쪽에 있습니다.
```

### 타로 사례

```text
일곱 장 타로 배열로 이 관계의 흐름을 봐 주세요. 핵심 카드, 장애물, 전환점, 상대의 행동, 검증 신호를 알려 주세요.
```
