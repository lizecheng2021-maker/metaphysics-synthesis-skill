# 形而上学総合 Skill

Codex と AI Agent のための四柱推命、梅花易数、六爻、風水方位分析、タロット解釈を扱う総合 skill です。

このリポジトリは、単なる占いプロンプトではありません。AI が象徴体系を構造的に扱うための再利用可能な手順です。体系を選び、結論を出し、根拠を示し、時期、行動、検証ポイントを整理します。

> 文化的、内省的、戦略的な参考用です。医療、法律、投資、メンタルヘルス、緊急時、安全上の助言を代替しません。

## 主な機能

- 結論、根拠、時期、行動、検証ポイントを分けます。
- 高確度の判断と低確度の推測を区別します。
- 複数体系を合成する前に、それぞれの体系を先に整合させます。
- 各方法を `runnable`、`partial`、`blocked` として扱います。
- 四柱推命は計算可能な命式情報と解釈を分離します。
- 梅花易数は時刻、数字、外応を明確にします。
- 六爻は初爻から上爻までの入力順を固定します。
- 風水は形勢を先に見て、理気や方位象意を後に扱います。
- タロットはスプレッド、seed、正位置/逆位置を記録します。
- 梅花易数の卦構造を計算するスクリプトを含みます。
- タロット抽カード用スクリプトと公開前のプライバシーチェックを含みます。
- 高リスク領域には明確な安全境界を置きます。

## 日本語の例

### 四柱推命の例

```text
この四柱推命の命式について、2026年から2036年までの仕事運と財運を分析してください。命式、大運、年運、高確度の結論、低確度の推測を分けてください。
```

### 梅花易数の例

```text
梅花易数で、この製品リリースがキャリア上の突破口になるかを見てください。問いが起きた時刻は 2026-06-12 10:36、外応は北西で上司がスケジュールを話していたことです。
```

### 六爻の例

```text
六爻で、このプロジェクトが昇進の主な根拠になるか判断してください。初爻から上爻までの数字は 5 / 4 / 25 / 12 / 22 / 17 です。
```

### 風水の例

```text
風水方位で私の席を分析してください。私は南東を向いて座り、直属上司は北西、大きなリーダーは南、他チームの責任者は東にいます。
```

### タロットの例

```text
七枚のタロットで、この関係の流れを読んでください。中心カード、障害、転換点、相手の行動、検証サインを出してください。
```
